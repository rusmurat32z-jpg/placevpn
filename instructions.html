1

Купите подписку через бота

3

Импортируйте подписку

Нажмите кнопку «+» в правом верхнем углу приложения. Выберите «Импорт из буфера обмена». Если появится запрос на разрешение вставки — подтвердите.

▶ Нажмите «+»
▶ Импорт из буфера
4

Выберите сервер и подключитесь

На главном экране появится подписка PlaceVPN с двумя серверами (Финляндия и Нидерланды). Выберите ближайшую локацию и нажмите синюю кнопку для подключения. При первом запуске разрешите VPN-конфигурацию.

▶ Показать скриншот
Совет: Для обновления серверов нажмите на иконку обновления рядом с подпиской. Серверы обновляются автоматически.

🛡 Белый список приложений

Некоторые приложения (банки, госуслуги) могут работать некорректно через VPN. Добавьте их в белый список, чтобы они использовали прямое подключение:

  • Откройте настройки v2RayTun (⚙ иконка шестерёнки)
  • Найдите раздел «Per-app Proxy» или «Разделение приложений»
  • Выберите режим «Обходить VPN» и отметьте нужные приложения
  • Рекомендуем исключить: Сбербанк, Тинькофф, Госуслуги, банковские приложения

Скачать с GitHub

⚡ Быстрое подключение

После оплаты нажмите кнопку «Подключить» в Telegram-боте — приложение откроется и настроит VPN автоматически.

— или настройте вручную —
1

Скачайте Hiddify

Перейдите на GitHub и скачайте Hiddify-Windows-Setup-x64.exe. Установите программу. Если Windows покажет предупреждение SmartScreen — нажмите «Подробнее» → «Выполнить в любом случае».

▶ Показать скриншот
2

Купите подписку через бота

Откройте @VPNplacewowbot в Telegram. Выберите тариф и оплатите картой любого банка РФ через ЮKassa.

▶ Показать скриншот
3

Скопируйте ссылку подписки

После оплаты бот пришлёт ссылку подписки. Нажмите на неё — она скопируется в буфер обмена.

▶ Показать скриншот
4

Добавьте подписку в Hiddify

Откройте Hiddify, нажмите «+» в правом верхнем углу, затем «Буфер обмена». Подписка импортируется автоматически — появятся два сервера PlaceVPN.

▶ Показать скриншот
5

Подключайтесь!

Нажмите большую кнопку на главном экране. Статус изменится на «Подключено» — VPN работает. Hiddify автоматически выберет лучший сервер.

▶ Показать скриншот
Альтернатива: Если Hiddify не подходит — попробуйте v2rayN. Добавьте подписку через меню «Серверы» → «Импорт из буфера обмена».

🛡 Белый список программ

Для корректной работы банковских приложений и других программ можно исключить их из VPN:

  • В Hiddify откройте Настройки → Per-app Proxy
  • Выберите режим «Bypass» (обход) для нужных программ
  • Рекомендуем исключить: браузер для онлайн-банкинга, клиенты банков
  • В v2rayN: используйте настройку маршрутизации для обхода российских доменов

🛡 Обход VPN для отдельных сайтов

В V2Box можно настроить маршрутизацию, чтобы российские сайты работали напрямую:

  • Откройте настройки V2Box → раздел «Routing»
  • Добавьте домены банков в список исключений
  • Примеры доменов: online.sberbank.ru, tinkoff.ru, gosuslugi.ru
  • Трафик к этим доменам будет идти напрямую, минуя VPN

Полезные советы

Как получить максимум от VPN

🏎

Выбирайте ближайший сервер

Финляндия обычно даёт наименьший пинг из России. Попробуйте оба и выберите самый быстрый.

🔄

Обновляйте подписку

Если серверы не подключаются — обновите подписку в приложении. Конфигурации обновляются автоматически.

🏦

Белый список для банков

Добавьте банковские приложения в исключения VPN — они могут блокировать вход через зарубежные IP.

🔋

Экономия батареи

VPN потребляет минимум ресурсов. Но если нужно сэкономить заряд — отключайте VPN, когда он не нужен.

❌

Отключите другие VPN

Перед подключением PlaceVPN убедитесь, что другие VPN и прокси отключены — они могут конфликтовать.
